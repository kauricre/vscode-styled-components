### Task 1: Fix #328 — multiline `styled(…)` call highlighting

The continuation pattern at `syntaxes/styled-components.json:78` — regex `(?:}>|\)\))` followed by the opening backtick — rescues templates whose opener line starts `}>` (multiline generics) or `))` (multiline attrs). A lone `)` before the backtick — the shape of a multiline `styled(…)` call — has no alternative, so the template stays `string.template.tsx`. Add a line-anchored lone-`)` alternative.

**Interfaces:**

      "kauricre.vscode-styled-components-modern"

    assert.ok(ext, "extension not found by id");
    await ext.activate();

    const doc = await vscode.workspace.openTextDocument({

        "  color: #ff0000;\n" +
        "`;\n",

      "vscode.executeDocumentColorProvider",
      doc.uri

});
